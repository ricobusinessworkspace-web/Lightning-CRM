# Agent-Anweisungen

Der projektübergreifende Workflow-Standard (Completion-Summary-Format,
Handover-Pflicht, Qualitätsstandards) liegt **außerhalb** dieses Repos und
gilt für alle drei aktiven Projekte gleich:

```
~/dev/coding-workflow-standards.md
```

Lies ihn zuerst, dann `HANDOVER.md` in diesem Repo für den aktuellen Zustand.

Er wird **nicht** in dieses Repo kopiert — sonst entstehen drei divergierende
Kopien, eine pro Projekt. Eine Änderung dort gilt sofort für alle.
